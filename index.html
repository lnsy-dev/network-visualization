Network Visualization

A 3D network graph built from plain HTML custom elements. Click a node or group to explore its metadata. Drag to rotate, Shift+scroll to zoom, scroll to pan the page.

Nodes

Nodes are the building blocks of any network graph. Each <network-node> element becomes a 3D object with a label and optional metadata.

Edges

Edges define relationships between nodes. Use the source and target attributes to connect two nodes.

Groups

Groups wrap related nodes in a wireframe boundary. They automatically resize as the simulation moves their members.

Shapes

Choose from sphere, cube, torus, or pyramid geometries using the shape attribute.

Metadata

Any HTML content inside a node or edge is stored as metadata and can be displayed when the element is selected.

Events

The component emits a metadata-shown custom event whenever a node or group is selected, making it easy to wire into your own UI.

Styling

Colors and background are inherited from CSS. Use standard styles to theme the visualization to match your site.

Core Concepts

The three primitives of every network graph: nodes, edges, and groups.

Features

Advanced capabilities that make the component flexible and easy to integrate.
